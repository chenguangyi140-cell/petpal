## ⭐ 产品方向重大反馈（用户 19:35–19:56）
用户对标完整 AI 宠物伴侣 App（状态条 开心/精力/亲密/饥饿 + 等级 + 底部 Tab 聊天/互动/声音/换装/化妆/设置 + 可拖拽旋转缩放的 3D 模型），指出 PetPal 当时"只是静态模型，不会动、不会说话、动作/换装/化妆都做不出效果"。

**经代码核查**：PetPal 其实已有完整骨架——
- `petStore`（mood 四维度衰减/互动/换装/化妆/睡觉）、`engine/emotion`、`skins`（interactions/wearables/makeup/actionForEmotion）
- `App.tsx` 六个功能 Tab 齐全；`PetStage` 已渲染心情条+气泡+点击 pet 调用 `tap()`
- `ChatPanel` + `chatStore`：LLM 优先、本地人设兜底（需用户填 API Key）
- 真正缺失的两块：
  1. **GLB 模型是死的**：`Model3DStage`/`ModelViewer` 仅慢速自转+微浮动，不响应 `action`/`emotion`/`tap`；PetStage 的点击气泡只对扁平 canvas 生效，对 GLB 模式不触发。
  2. **完全没有语音（TTS）**：全仓无 `speechSynthesis`，audio 模块仅做麦克风可视化。

**用户决策（19:56）**：选 **D —— 全都要，但分阶段排期，慢慢做。**

### 分阶段路线图（已存档 docs/ROADMAP.md）
- P1 让宠物"活"：GLB 模型响应 action/emotion/tap（idle/跳/吃/睡/开心）+ 给 GLB 模式补点击气泡 + 浏览器 TTS 让宠物说话（免费，无需 Key）。
