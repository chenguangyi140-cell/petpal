## 1. 版本哲学

- **MVP 已达成**：六大核心功能（照片、对话、情绪、动作、换装、化妆）全部可用，零成本可运行。
- **不做过度工程**：每个新功能都需回答「是否服务于『陪伴』体验」与「是否零成本/可离线」。
- **渐进增强**：先稳核心，再补美术资产与高级能力。

## 5. 已知问题

### 🔴 国内手机访问不稳定（根因已确认）

**现象**：手机访问 `https://chenguangyi140-cell.github.io/petpal/` 与 `https://petpal-theta-lake.vercel.app` 均「一直转圈」。

**排查结论（服务器端实测正常）**：
- GitHub Pages：HTTP 200，加载 0.78s，资源全 200
- Vercel：HTTP 200，1.07s，manifest Content-Type 正确、sw.js 正确，PWA 可安装

**根因**：两个域名均为**境外域名**，受中国大陆手机网络环境影响不稳定。**此问题与应用代码、PWA 配置无关**——两次部署在服务器侧均已验证通过。

**方案**：
1. **国内托管（推荐，需用户操作）**：腾讯云 EdgeOne Pages / 腾讯云 COS / 阿里云 OSS 三选一，绑定国内可达域名。
   - 三者均需**实名认证**（国内托管政策强制，AI 无法代做）。
   - 选定后我可准备对应的一键部署配置 / 脚本。
2. **临时体验**：同 Wi-Fi 下用本地 HTTPS 服务 `node serve-local.js` → 手机访问 `https://<电脑局域网IP>:4174`（需点「继续」忽略自签证书警告）。限制：电脑不能关、需同 Wi-Fi、自签证书可能拦 PWA 安装（仅交互体验）。
