# PetPal 授权与收费（v1 轻量手动模式）

> 状态：**第一步（轻，不动后端）**。验证「是否有人愿意付费」，不接支付、不做自动扣费。

## 定价模型

| 项目 | 价格 | 说明 |
|---|---|---|
| 首次激活 | ¥99 | 一次性费用，激活后开始计时 |
| 每月续费 | ¥10 / 月 | 到期需重新填入新激活码 |
| 授权范围 | 一个手机一个授权 | 设备绑定；换手机/清缓存需重新激活 |

## 工作原理（本地、无后端）

1. 作者用 `scripts/gen-code.mjs` 生成激活码（编码「天数 + 校验和」）。
2. 用户付款后，作者把码发给用户。
3. 用户在 App「会员激活」页输入码 → 本地校验 → 解锁，记录 `expiresAt`。
4. 每 30s 检查一次，过期后强制重新激活。

激活状态保存在本机 `localStorage`（key `petpal.license`），不上传任何服务器。

## 生成激活码

```bash
npm run gen-code          # 默认 30 天（对应一次 ¥10 月续费）
npm run gen-code 30       # 显式指定天数
```

输出形如 `PP-XXXX-XXXX-XXXX-XXX`，直接发给已付款用户即可。

> ⚠️ 算法位于 `src/services/license.ts` 与 `scripts/gen-code.mjs`，两处须保持同步。

## 开发/演示一键激活

URL 加 `?demo=petpal` 可跳过激活直接体验（例如 `https://mypetpal.cn/?demo=petpal`）。
**发布前请移除 `src/App.tsx` 中的该 demo 分支。**

## 已知限制（轻量模式）

- 本地校验可被技术用户逆向伪造，仅用于验证付费意愿，**不是真正的收费防护**。
- 无自动扣费：每月需手动发码、用户手动填码。
- 设备绑定靠 localStorage，清缓存即失效。
